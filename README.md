# SimpleLinkManager

Моё расширение для работы с ссылками.

---

## Управление(Как оно работает)

В текстовом поле пишем ссылки или импортируем ссылки в формате .тхт или в .json файл. Потом нажимаешь кнопку "открыть все ссылки сразу" и все ссылки открываются. Если нужно сохранить эти ссылки, то можно их сохранить в формате .txt или .json.
